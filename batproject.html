Automating Data Wrangling for Bat Accoustic Data

Project Overview:

In the Summer of 2023, I volunteered with PhD Candidate Robin Rowland by completing a literature review on the environmental factors that increase the occurrence of accoustic activity of bats. As part of that project I developed a program in R that would step her through customisable data cleaning of her accoustic data from Kaleidoscope, a bioaccoustic sound analysis tool. Turning a several hour-long task into one only requiring a few minutes.

You can see and access this document at my Github.


An example accoustic dataset.

The program featured a readme.docx explaining the required steps to use the program, ensuring clarity and making me reduntant from the project at completion.

Outcomes:

The final deliverable of this project was a program that identified any misnomers or mispellings of bat species, including common names, and stepped the user through replacing them to the appropriate scientific name for each accoustic recording instance. The program would then use a given database and assign each accoustic instance to a guild and consolidate all given datasets into one aggregated dataset. This minimises the time it takes to clean the data by hand regardless of the skill level of the user and can be adjusted to suit individual datasets using only CSV's input by the user.
